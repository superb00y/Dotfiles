# Ax-Shell Project Overview

Ax-Shell is a highly customizable and hackable desktop shell designed for use with Hyprland, a dynamic tiling Wayland compositor. It provides a comprehensive set of features to enhance the desktop experience, including an application launcher, a dynamic system bar, a power menu, dashboards, and various utility modules. The project emphasizes modularity, dynamic theming, and deep integration with the Hyprland environment.

## Technologies Used

*   **Python:** The core programming language for the application logic and modules.
*   **Fabric (Python library):** Used for building the graphical user interface (GUI) components, leveraging GTK for rendering.
*   **Hyprland:** The Wayland compositor that Ax-Shell integrates with, providing a responsive and dynamic desktop environment.
*   **Matugen:** A versatile color generation tool that dynamically creates color themes from user-selected wallpapers, applying them across both Hyprland and Ax-Shell's CSS.
*   **Shell Scripting (Bash):** Employed for installation, updates, and initial launch processes.
*   **`uwsm`:** A Wayland utility essential for managing and launching applications within the Wayland session.
*   **`yay`/`paru`:** Arch User Repository (AUR) helpers used for streamlined package installation on Arch Linux distributions.
*   **Numerous CLI Utilities:** Integrates with various command-line tools such as `brightnessctl`, `cava`, `cliphist`, `playerctl`, `swww`, `tesseract`, `tmux`, and `wl-clipboard` to provide diverse functionalities.

## Architecture

Ax-Shell follows a modular architectural pattern. Key components include:

*   **`main.py`:** The primary entry point of the application, responsible for initializing the core Fabric application and its main UI components like the Bar, Dock, and Notch.
*   **`config/` directory:** Contains configuration-related files.
    *   **`config/config.py`:** A Python script that serves as a GUI settings application. It defines default configurations, manages user-specific settings via `config.json`, and generates Hyprland configuration snippets. It also handles `matugen` integration for dynamic theming.
    *   **`config/config.json`:** Stores user-defined preferences, keybindings, layout options, and visibility settings for various modules.
*   **`modules/` directory:** Houses individual Python modules, each implementing a specific feature or UI component (e.g., `bar.py` for the system bar, `launcher.py` for the app launcher/calculator, `dock.py` for the application dock).
*   **`styles/` directory:** Contains modular CSS files that define the visual appearance of Ax-Shell's components. `main.css` imports all other style sheets, and `colors.css` is dynamically generated by `matugen` to reflect the current color theme.

## Building and Running

### Installation (Arch Linux)

For Arch Linux users, the recommended installation method is via the `install.sh` script:

```bash
curl -fsSL https://raw.githubusercontent.com/Axenide/Ax-Shell/main/install.sh | bash
```

This script will:
1.  Clone or update the Ax-Shell repository in `~/.config/Ax-Shell`.
2.  Install all necessary system and Python dependencies using `yay` or `paru` (AUR helpers).
3.  Install required fonts (Zed Sans and Tabler Icons).
4.  Run the initial configuration using `config/config.py`.
5.  Launch Ax-Shell.

### Manual Installation

1.  **Install System Dependencies:** Install `Fabric`, `fabric-cli`, `Gray`, `Matugen`, `brightnessctl`, `cava`, `cliphist`, `gnome-bluetooth-3.0`, `gobject-introspection`, `gpu-screen-recorder`, `grimblast`, `hypridle`, `hyprlock`, `hyprpicker`, `hyprsunset`, `imagemagick`, `libnotify`, `noto-fonts-emoji`, `playerctl`, `swappy`, `swww`, `tesseract`, `tmux`, `uwsm`, `wl-clipboard`, `wlinhibit`.
2.  **Install Python Dependencies:** Install Python packages such as `ijson`, `numpy`, `pillow`, `psutil`, `requests`, `setproctitle`, `toml`, `watchdog` (preferably in a virtual environment).
3.  **Clone Repository:**
    ```bash
    git clone https://github.com/Axenide/Ax-Shell.git ~/.config/Ax-Shell
    ```
4.  **Run Initial Configuration:**
    ```bash
    python ~/.config/Ax-Shell/config/config.py
    ```
5.  **Launch Ax-Shell:**
    ```bash
    uwsm -- app python ~/.config/Ax-Shell/main.py > /dev/null 2>&1 & disown
    ```
    (Note: The `launch.sh` script in the repository suggests using a `fabricenv` virtual environment, but `install.sh` installs dependencies globally via AUR. The above command is more consistent with the `install.sh` approach.)

### Running Ax-Shell

*   **Automatic Launch:** Ax-Shell is designed to be launched automatically when Hyprland starts. This is typically configured in your `~/.config/hypr/hyprland.conf` using an `exec-once` command that points to the Ax-Shell `launch.sh` script or directly to `main.py` via `uwsm`.
*   **Restarting:** To restart Ax-Shell (e.g., after applying configuration changes), you can use the command:
    ```bash
    killall ax-shell; uwsm app -- python ~/.config/Ax-Shell/main.py
    ```
    Alternatively, a keybinding for restarting the shell is usually configured in `config.json` and `hyprland.conf`.

### Configuration GUI

To open the graphical settings application for Ax-Shell:

```bash
python ~/.config/Ax-Shell/config/config.py
```

This GUI allows users to customize keybindings, appearance settings (wallpaper directory, profile icon, vertical layout, dock behavior, module visibility), and system integrations (Hyprland configuration files).

## Development Conventions

*   **Python Best Practices:** Uses `setproctitle` for clear process identification. Employs `try-except` blocks for error handling.
*   **Modular Configuration:** Leverages `config/config.py` for default settings and dynamic configuration generation, with `config/config.json` serving as the user-specific override file.
*   **Dynamic Theming:** Deep integration with `matugen` for generating color palettes from wallpapers, applied to both Hyprland and Ax-Shell's UI.
*   **UI Development:** Built upon the Fabric Python library, which provides GTK-based widgets for creating the user interface.
*   **Hyprland Integration:** Generates `hyprland.conf` snippets and reloads the Hyprland configuration using `hyprctl reload` to apply changes.
*   **Keybinding Management:** Keybindings are centrally defined and configurable through `config/config.py` and stored in `config.json`.
*   **Styling:** Utilizes a modular CSS approach with individual `.css` files for different UI components, all imported into `main.css`. Dynamic color variables are managed in `styles/colors.css`.
*   **No Explicit Testing Framework:** No dedicated testing framework was immediately apparent (e.g., `pytest`, `unittest`).
*   **No Explicit Contribution Guidelines:** No `CONTRIBUTING.md` or similar file was found.

This `GEMINI.md` serves as a comprehensive guide for understanding, building, running, and contributing to the Ax-Shell project.
